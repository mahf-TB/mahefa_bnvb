# Portfolio Mahefa Bienvenu

Portfolio construit avec Next.js, TypeScript, Tailwind CSS et shadcn/ui.

```bash
npm install
npm run dev
```

Ouvrez ensuite [http://localhost:3000](http://localhost:3000).

## Variables d’environnement

Le formulaire de contact utilise les variables suivantes :

```env
NEXT_PUBLIC_EMAILJS_SERVICE_ID=
NEXT_PUBLIC_EMAILJS_TEMPLATE_ID=
NEXT_PUBLIC_EMAILJS_PUBLIC_KEY=
```
